# llms-for-cta-glm

Few-shot, RAG and CoT baselines of *Improving Column Type Annotation Using LLMs* (Babamahmoudi, Rafiei, Nascimento, VLDB 2025 TaDA workshop), run with GLM-4-9B (shared vLLM server) on the RAG4CTA datasets (GitTablesSC / GitTablesDB, TURL, BiodivTab-DB / Wiki, SOTAB). Official code: https://github.com/drafiei/llms-for-cta (VizNet only, OpenAI only).

| file | what it does |
|---|---|
| `cta_glm.py` | faithful port of the official `cta.py` to GLM-4-9B and Mistral embeddings (VizNet sample, 7 configurations) |
| `cta_ours.py` | few-shot (`--method fewshot`, 5 random train examples) and RAG (`--method rag`, 5 most similar columns of a 2000-column train sample, Mistral `mistral-embed`) on our datasets, single-column setting, `--setting single_label|multi_label` |
| `cta_cot.py` | CoT, multi-column setting: one call per table, 4 examples with a reasoning step |
| `gen_cot_examples.py` | GLM writes the reasoning of the 4 CoT examples (train tables, scored by a GLM judge), `data/cot_examples/` |
| `cot_indexed_test.py` | experiment that led to the numbered answer format of `cta_cot.py` |
| `embed_refs.py` | recomputes the reference vectors of the official repository with Mistral |
| `run_all_*.sh` | launch scripts (TURL in 8 shards) |

All result files have the 10 fields of RACOON_CTA.py and are scored with `scripts/eval/eval_racoon.py` of RACOON_yu (the metrics of the RAG4CTA `test` branch). `RACOON_SRC` points to `RACOON_yu/src` (loader, label_resolve, context_fit). Each setting is scored on the columns of its own data folder (`single_label/` = one gold type, `multi_label/` = two or more).

## Decisions
- The examples of few-shot, RAG and CoT never contain a column with the same first-6-cell content as any test column (the datasets repeat columns across train and test). Near-duplicates (cell Jaccard >= 0.5) are not removed, as in the official code; they inflate RAG on GitTablesSC / DB (25% / 23% of the test columns have one), none on TURL.
- CoT answers as `["Column 1: type", ...]` instead of a bare list. The bare list gave a wrong length for 50% of the tables with 21-40 columns and for all wider tables. No retry, no repair: a column whose number is missing gets an empty prediction.
- CoT reasoning examples are generated by GLM-4-9B from the true types of train tables (the original has 4 hand-written VizNet examples).
- Multi-label prompts follow the wording of RACOON appendix A.2 ("one or multiple types", answers `t1; t2`).
